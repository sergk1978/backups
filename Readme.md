Программа предназначена для резервного копирования каталогов с файлами, а также для удаления старых копий.
Оформлена в виде файла с расширением .exe.
Для своей работы программа использует вспомогательный файл path.txt, в котором на каждой строке задаются параметры: 
        1 строка - путь источника (откуда копировать)  
        2 строка - путь назначения (куда копировать)
        3 строка - папки и файлы, которые исключаются при копировании (заполняются через запятую)
        4 строка - количество дней для определения устаревших папок, которые будут удалены

При запуске программы запускается окно консоли, где отображается ход ее действий.
